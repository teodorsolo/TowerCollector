Corvus Instinct is a self-hosted positioning service: it tells a device where it is from the Wi-Fi access points and cell towers it hears, without asking Google, Apple or anyone else at query time. It speaks the Mozilla Location Service API, so Tower Collector can upload to it without changes to the measurement format.

Coverage today is Ukraine and its border belt. No API key or account is needed to contribute.
